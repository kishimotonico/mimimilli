## Description

DRAFT-17 / DRAFT-24 を統合したもの（2026-08-19の棚卸し）。DRAFT-24 が「DRAFT-17に含まれるスリープタイマーをデスクトップでも」という切り出し構想で、要件が二重管理になっていた。

## 現状（2026-08-19 実測）

- スリープタイマーは未実装（`rg -i 'sleepTimer|スリープタイマー' client/` でドキュメント以外にヒットなし）
- PWA manifest も未整備（`rg 'manifest\.json|webmanifest' client/` でヒットなし）
- ADR-0006 では PWA を将来スコープ、スリープタイマーは PWA 側の記述として置かれている

## スリープタイマー（本体）

音声作品アプリとしてニーズが高い機能。デスクトップ・モバイル共通の実装として作り、UIの置き場所だけ分岐させる。要件はユーザーが整理予定（2026-07-19時点から未着手）。

検討ポイント:
- タイマーのプリセット / 自由入力
- フェードアウトの有無
- トラック末尾まで再生してから停止するオプション
- UIの置き場所（プレイヤーポップアップ / フルスクリーンプレイヤー / モバイルのミニプレイヤー）
- タイマー残り時間の表示

## PWA（ホーム画面追加）

manifest追加でホーム画面に追加可能にし、テーマカラー・アイコンを整備する。オフラインキャッシュは初期スコープ外。外出先アクセス（Tailscale等）や帯域向けトランスコードもスコープ外で、必要になったら別途起票する。

モバイルシェル（DRAFT-19）が動いてからでないと意味が薄いので、優先度は本体より後。

## 受け入れ条件（案）

- スリープタイマーで指定時間後に再生が停止する（デスクトップで動く）
- ホーム画面に追加してスタンドアロン表示で起動できる

## 進め方

スリープタイマーはPWAに依存しないので先に単独で着手できる。PWA本体（manifest・アイコン）はモバイルシェル完成後に切り出してタスク化する。
