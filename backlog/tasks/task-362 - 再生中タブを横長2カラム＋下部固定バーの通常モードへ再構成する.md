## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
ドッグフーディングの結果、再生中タブ（appMode nowPlaying、client/src/features/player/ui/NowPlayingView.tsx）の中央寄せ縦1カラム構成はPCの横長画面を持て余すため、横長レイアウトへ再構成する。確認済みモック: https://claude.ai/code/artifact/818e5287-6d41-4aa2-bf1b-50fe21c5bcee （閲覧できない場合も本タスクの記述だけで実装可能なこと）。

確定仕様:
- 左カラム: カバー大＋作品タイトル・トラックタイトル＋「この作品の詳細を見る」導線（既存機能を維持）
- 右カラム: トラックリストを常時表示に変更（折りたたみ廃止）。カラム内部のみスクロール、現在トラックのハイライトとクリック切替は既存挙動を維持（NowPlayingTrackList.tsxを常時表示化）
- 下部バー: 帯（背景）は全幅、中身は中央寄せの幅W。上から 長いシークバー（NowPlayingScrub.tsx、時刻表示を含む。AB区間ハイライト＋角括弧ハンドル操作は現状維持）→トランスポート（PlayerTransportControls.tsx）→AB設定（ABRepeatBar.tsx）
- ページ全体のスクロール禁止: 100dvh内に収める。スクロールは右カラム内部のみ。ウィンドウを縮めてもページスクロールを出さない
- PlayerDockの扱い: nowPlaying中はPlayerDock（バー/ポップアップ、client/src/features/player/ui/PlayerDock.tsx、App.tsx:222付近で常駐）を描画しない。再生中タブ自体が全操作を持つため二重表示になる。playerUiModeAtom（bar/popup）の保存値は変更せず、他モードへ戻ったら保存値どおりに復元する。AppShellのtransportBar領域（AppShell.tsx:34付近、72px確保）もnowPlaying中は占有しない
- 空状態（未再生時）・URL /now-playing・左ナビのバッジは既存挙動を維持

寸法の基準（CSS変数で一元定義。数値は実装時に微調整可）:
- 幅W: ビューポート基準 calc(100vw - 96px)（左右48px余白）。シェル本文基準にしない（後続の没入モードがビューポート全面のため、基準が違うと切替時に位置が変わる）
- 左右カラム比は目安2:3、gap 24px。カバーは左カラム内で最大化（上限目安 min(56vh, 480px)）
- 対応最小ビューポートは幅1024px。それ未満は現行デスクトップシェルの挙動に従い専用対応しない（768px以下はMobileShell未実装の責務外、docs/design-system.md参照）

上流設計（後続TASK-363の前提。必ず守る）:
- シーク行（シークバー＋時刻表示）は、通常/没入の分岐より上の永続祖先に1インスタンスだけ置き、ビューポート基準のfixed配置（下端からのオフセットと幅WをCSS変数で定義）とする。トランスポート/AB行はシーク行の下の領域に描画し、それらを非表示にしてもシーク行の位置・寸法が変わらない構造にする
- 帯（バー背景）や角丸の器などの装飾はシーク行スロットの外の装飾層として持ち、シークバー本体と密結合させない
- 高頻度atom（playerCurrentTimeAtom等）の購読leafは再生中タブ配下ではNowPlayingScrubのみ。あわせてdocs/HANDOFF.mdの購読leaf一覧（現状3leaf記載でNowPlayingScrubが漏れている）を現状に書き換える
- デザインは docs/design-system.md 準拠

運用: 統合ブランチ feat/now-playing-redesign を切り、配下の作業ブランチ＋git worktreeで実施。UIレイアウト変更のため pnpm test:smoke 必須。既存smokeのロケータが壊れる場合は追随修正する
