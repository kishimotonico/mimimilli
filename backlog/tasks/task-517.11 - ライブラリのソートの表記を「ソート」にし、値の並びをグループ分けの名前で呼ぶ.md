## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
ユーザーの指摘（2026-11-24）: 「値の並び」「作品の並び」が分かりにくい。「並び」より「ソート」のほうが分かりやすい。ライブラリの並べ替えの画面の表記を「ソート」にそろえ、値一覧の並べ替えは内部の語「値」を出さずにグループ分けの名前で呼ぶ。設定のタグ prefix の「並び順」（手で並べる順番）は対象外。docs の内部の用語（ADR の「並び」）は変えなくてよいが、design-system.md・requirements-v4.md の画面の表記の記述は合わせる。
