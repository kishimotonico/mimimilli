## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
ADR-0043 の置き換え順の3。ネイティブ dialog に由来する仕組み（inert を避けるポータル、`openModalDialogsAtom`、Tab 循環の補完、cancel の伝播止め、トーストの付け替え、backdrop クリックの判定）と、TASK-529 でその上に積んだ例外処理を無くし、Esc とフォーカスを Ark の層に1系統でまとめる。子タスクで進め、ここでは全体として満たすことを確かめる。

## 4. 「Esc」にツールチップを足す

現行（3つ目の箇条書きの後に足す）:
> - ポップアップ系の層（メニュー、ポップオーバー、ダイアログ、コンボボックス、セレクト）の Esc は、Ark UI の dismissable layer に一本化する。自前の document の Esc リスナーで層を閉じない

新（この箇条書きの直後に1項目を足す）:
> - ツールチップは層に数えない。Ark UI のツールチップは dismissable layer のスタックに入らず、表示中の Esc を document の capture 段で `stopPropagation` する。window の bubble 段で Esc を受ける処理（再生中の層、一覧の選択解除）や React のハンドラに Esc が届かなくなるので、`closeOnEscape: false` を既定にし、ツールチップは Esc を消費しない

## 5. 「ダイアログ」

現行:
> - ダイアログはネイティブ dialog から Ark UI の Dialog へ寄せる。次の既存の仕組みが要らなくなり、Esc とフォーカスがほかの層と1系統になる: inert を避けるためのポータル、`openModalDialogsAtom`、Tab 循環の補完、cancel の伝播止め、トーストの付け替え、backdrop クリックの判定
> - 置き換えは最後の段階で行う。それまでのネイティブ dialog の中のメニューとポップオーバーは、ポータル先を dialog の中にする

新:
> - ダイアログはネイティブ dialog から Ark UI の Dialog へ寄せる。次の既存の仕組みが要らなくなり、Esc とフォーカスがほかの層と1系統になる: inert を避けるためのポータル、`openModalDialogsAtom`、Tab 循環の補完、cancel の伝播止め、トーストの付け替え、backdrop クリックの判定

3つ目の箇条書き（「backdrop クリックの二重クローズを防ぐガード」）以降は変えない。トースト、`alertdialog` の外側クリック（Ark UI の既定では閉じない）、modal が body の `pointer-events` を止めること、層を開いたままの backdrop の規則は、段階4の設計で決めたあと、この節に現在形で足す。
