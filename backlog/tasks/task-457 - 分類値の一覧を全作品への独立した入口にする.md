## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
ADR-0026 の決定を実装する。分類値一覧は現在の絞り込みとは独立した全作品への入口とし、件数は全体の件数を表す。値一覧に効かない検索語・フィルタを効いているように提示しない。値一覧から作品一覧へ戻るときに値の選択が既存の絞り込みを引き継ぐのか置き換えるのかは ADR で決めていないため、着手時に ADR-0013 の置換規則と URL 復元の意味が一致する形で決める。
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 分類値一覧が現在の絞り込みと独立した全作品の集合を対象にする
- [ ] #2 件数が全体の件数であることを画面から読み取れる
- [ ] #3 値一覧の表示中、適用されない検索語・フィルタが効いているように提示されない
- [ ] #4 値一覧の件数と作品一覧の件数に別のラベルが与えられている
- [ ] #5 URLから復元した状態でも入力欄・一覧・件数が同じ条件を表す
- [ ] #6 通常クリック・AND追加・値を選ばず戻る・ブラウザ戻る/進む/URL直アクセスの4操作について、viewとスマートフォルダー、q、tagsとyear、sortの保持・消去・置換が決まっている
- [ ] #7 値一覧でのAND追加時、追加中の条件の提示先と適用先が決まっている
<!-- AC:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
通常クリックが選択タグ全体を置換して作品一覧へ遷移することは ADR-0013 で確定済みであり、未決の対象ではない。未決なのは、その置換が q・view・スマートフォルダー・sort をどう扱うか。入力欄を隠して条件を裏に残し、選択先で説明なく復活させる実装は認めない。スマートフォルダーの作品検索qの扱いは TASK-462 が担当する。

AC6・7の決定（2026-09-24）: 値一覧へ入った時点で、値一覧に効かない条件（q・tags・year・スマートフォルダー）は消去し、sortとviewは保持する。通常クリックは全作品＋そのタグ1件で作品一覧へ遷移する（ADR-0013）。AND追加は値一覧では提供せず、作品一覧のチップ内候補だけで提供する。値を選ばず戻る操作は全作品一覧へ。ブラウザの戻る・進むとURL直アクセスは同じ状態を復元し、入力欄・一覧・件数を一致させる。
<!-- SECTION:NOTES:END -->
