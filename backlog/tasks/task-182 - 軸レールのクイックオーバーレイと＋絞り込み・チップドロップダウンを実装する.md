## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
ADR-0012 / DRAFT-50 のフェーズ3後半。値選択の入口を3つ揃える。既存の ui/preview/useAnchoredPopover.ts を共通基盤として使うが、クランプ対象コンテナが .mle-prv__meta / .mle-prv__body にハードコードされているため、任意のコンテナを指定できるよう拡張する。

1. 軸レールのクイックオーバーレイ
- ホバー約200ms でアンカー表示。検索ボックス＋ソート付きの値リスト
- ポインタが軸レールとオーバーレイの両方の外へ出たら閉じる（両者の間を横切る移動で閉じないこと）
- クリック / フォーカス+Enter は結果面の値一覧ページへ遷移する。オーバーレイ表示中のクリックも再表示ではなく遷移
- キーボード（統括判断で確定済み）: 軸行フォーカス中の ArrowRight でオーバーレイを開き、内部を上下キーで移動、Escape で閉じて軸行へフォーカス復帰
- 選択の既定は置き換え

2. チップ列の「＋絞り込み」
- 軸 → 値 の2段オーバーレイ。既定は AND 追加で、その旨のヒントを表示する

3. チップクリック
- 同じ軸の兄弟値ドロップダウン（検索付き）を開き、選択で置き換え乗り換え

全入口共通: Ctrl+クリックで既定動作を反転する（置き換え既定の入口では AND 追加に、AND 追加既定の入口では置き換えに）。結果面の値タイル/行も同様で、クリック＝置き換え、Ctrl+クリックまたはホバーで出る追加ボタンで AND 追加。

オーバーレイ内の値リストは TASK-181 の値一覧と同じデータ・同じソートキー注入を使う（描画は簡易版でよいが、ロジックを二重に書かない）。
