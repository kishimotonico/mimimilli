## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
TASK-365のコントロール1行統合（.mle-nowplaying__controls を grid: 1fr auto 1fr、client/src/styles/shell/player-a.css:659付近）に対するCodexレビュー指摘のフォローアップ。

問題: 中央のPlayerTransportControlsが約500pxを占めるため、ウィンドウ幅が狭い場合（900px程度、または1280pxで長いAB時刻「h:mm:ss」を表示する場合）にAB側の文言・時刻が折り返し、ボタンが縮んで1行配置が崩れる。

修正方針:
- まず実機で崩れの発生条件を確認する（1024px/1280px、AB時刻が長いケース。ABRepeatBarの時刻を長い値にして確認）
- サポート下限の1024px〜で1行が崩れないようにする: AB側のwhite-space: nowrap、gap・padding の圧縮、グリッド列のminmax調整など
- それでも収まらない幅では無理に1行を維持せず、メディアクエリでAB行を下段に落とす等の秩序ある退避にする（文字の折り返し・ボタン潰れという乱れた崩れ方をなくすのが目的）
- 1600pxの見た目（トランスポート中央・AB右端）は変えない

運用: masterからブランチ task/366-controls-narrow を切り .worktrees/task-366 で作業。UIレイアウト変更のため pnpm test:smoke 必須
<!-- SECTION:DESCRIPTION:END -->
