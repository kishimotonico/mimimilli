## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
グリッドのカバー表示を切替可能にし、サイズスライダーの体感分解能を改善する（Eagle風）。

背景: 現状は aspect-ratio:1 固定＋object-fit:cover で、DLsiteの4:3サムネは上下トリミングされる。スライダー（min100/max280/step1）は細かいが、列数が auto-fill+minmax(size,1fr) で決まるため、列数が変わる瞬間しか見た目が変わらず粗く感じる。

方針:
- 表示形式を2種用意し、AddressBar のビュー切替まわりに配置:
  1. 1:1タイル（現行のトリム表示）
  2. 原寸（ジャスティファイド）: 画像のアスペクト比を保ったまま行ごとに敷き詰める（行高さターゲット＝スライダー値、行末で比率調整）
- スライダーはタイルの「目標サイズ」に近い連続的な反映へ改善（1:1タイルでは列数ジャンプの緩和、ジャスティファイドでは行高さに直結）
- 形式・サイズは localStorage 永続化（既存の libraryViewModeAtom/libraryTileSizeAtom の流儀）
- グリッドインスペクタ・キーボードナビ（2次元フォーカス移動）が両形式で機能すること

関連: client/src/features/library/ui/WorkGrid.tsx, app/ui/AddressBar.tsx, model/gridSizing.ts, atoms.ts, styles/shell.css .mll-grid*
