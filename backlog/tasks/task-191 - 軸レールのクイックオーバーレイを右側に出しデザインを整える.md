## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
実機での使用感の指摘（2026-08-05）による改善。ライブラリ再設計のブランチ内で対応し、マージ前に解消する。

## 1. 表示位置を右側にする
現在オーバーレイは軸レール行の下側に出るが、軸レールは画面左端の縦並びなので下方向は不自然。右側に出すのが操作の流れに合う。軸行のアイコンが右向き矢印であること、キーボードでも ArrowRight で開く仕様（ADR-0012 §7）であることとも一致する。

左右の反転フォールバックは設けない。軸レールは画面左端に固定されているため、デスクトップ幅で右に余白が無いケースは実質発生しない。それが起きるのはモバイル幅であり、そこは ADR-0006 のモバイルUI戦略として別の設計が必要な領域なので、ここで先回りした分岐を作らない（AGENTS.md「過度なフォールバックは禁止」）。垂直方向のみ、軸行の高さを基準に画面外へはみ出さないようクランプする。

## 2. 検索インプットの見た目を整える
オーバーレイ内の検索ボックスが黒い太枠で強調されすぎていて、パネル内で浮いている。フォーカスリング自体は残してよいが、非フォーカス時のボーダーの太さ・色を docs/design-system.md のカラートークンに沿った控えめなものにする。値リストが主役でありインプットは従、という視覚的な優先順位にする。

## 3. ソートをアイコンボタン＋インライン展開にする
現在ソートUIが常時表示されていて場所を取っている。ソートアイコンボタンを置き、クリックでオーバーレイ内にインライン展開する形にする。

統括判断: 入れ子の浮遊レイヤー（ポップオーバーの中にポップオーバー）は作らない。フォーカス管理と Escape の二重化で壊れやすいため。オーバーレイのパネル内でインラインに開閉する形とする。実装してみて窮屈で使いにくいと判断した場合は、現状の常時表示のままでよい（その場合は理由を報告すること）。

対象: client/src/features/library/ui/AxisQuickOverlay.tsx / AxisValueQuickList.tsx / ui/preview/useAnchoredPopover.ts / client/src/styles/shell.css
