## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
workRegister.ts の createWorkFromFolder と createWorkFromAudioFile は、孤立メタの読み込み→MetaParseError→identity衝突判定→metaPatch構築（タイトル・タグ・DLsite適用・URL）→restore/register の流れがほぼ同じで、違いはmetaPathの求め方・祖先/子孫ガード・DLsite適用先ディレクトリだけ。Scanner側の registerFolderWork/registerFileWork/restoreFolderWork/restoreSidecarWork も同形で、identity衝突判定は snapshotForRestore にも別実装がある。ADR-0032で配置形式はmetaPathから決まるようになったので、形式ごとの差を小さな戦略に閉じ込め、登録・復元・プレビューを1実装にする。Scannerから単一作品の登録・投影を外すかどうかは、統合後の形を見て判断する。
