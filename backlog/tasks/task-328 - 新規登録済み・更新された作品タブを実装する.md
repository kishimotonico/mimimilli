## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
設計レビュー2026-08-14。ScanNewWorks（新規検出した作品）はnewWorkIdsを参照しているがreal adapterでは常に空のため表示されない。TASK-325で追加するWork ID配列を使って作り直す。UI仕様: 新規登録済みタブ＝今回ライブラリに入った作品（候補承認による登録分と、mimimilli.jsonがあって自動で入った分の両方を含む）。列はタイトル・フォルダー・外部連携・トラック。タイトルはクリックでインライン編集（既存の保存挙動を踏襲）／外部連携列はRJコードと状態を併記し、状態は「連携済み」（取得・適用完了）「取得待ち」（順番待ちまたは処理中、グレー表示。異常ではないため警告色を使わない）「失敗」（コードはあるが取得できず、赤）「—」（RJコードなし）の4種。DLsite以外の連携先が増えても列を増やさずに済むよう列名は外部連携とする／説明文は「今回ライブラリに入った作品です。作品情報ファイルがあったものは自動で、未登録から追加したものはその操作で入りました。タイトルをクリックすると直せます。」。更新された作品タブ＝メタファイルが外部で更新され再投影された作品。列は新規登録済みと同じでよい。説明文は「スキャン時に作品情報ファイルの変更を取り込みました。」。どちらもテーブル内でスクロールし、表示上限を超える場合は件数を明記する。
