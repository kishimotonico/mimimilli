## Description

ファイルモードのカラムビューは直近1階層しか祖先を表示せず、深い物理パスで現在地と戻り先を把握できない。物理FSファイラーという位置づけを維持し、祖先を省略可能なパンくずとして表示する。

前提（統合済みの変更）: TASK-428.18 が Files 系を大きく改修済み。404と5xx/通信失敗の区別（ApiRequestError.status===404 で判定、404では合成entryを組み立てない）、単一ファイル作品の登録済みバッジと実タイトル表示（単一ファイル作品のときだけ GET /works/:id を追加取得）、再生ボタンの状態別トグル、プレビューの閉じる・ドラッグリサイズ（filesPreviewWidthAtom、localStorage永続化、320〜720pxクランプ）・狭幅時の全幅切替（container query、720px以下）、絶対パスコピー（joinPath(rootFolder, entry.path.split("/")) で実OS絶対パスを合成、ローカル専用の明示は常時表示のヒント文）、選択対象が一覧から消えているケースの対象なし表示（isFilesSelectionMissing、FilePreviewMissingSelection）。

TASK-428.18 の担当（エージェント名 t428-18）が worktree を残して質問に対応できる。
