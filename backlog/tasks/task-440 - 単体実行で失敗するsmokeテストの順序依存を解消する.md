## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
smokeテスト「未登録タブでRJコードを編集でき、候補を1件ずつ除外して元に戻せる」が、単体実行時には再現性のある形で失敗し、フル実行（4ワーカー並列）では毎回パスする。

TASK-430 の実装担当が発見。切り分けとして、メインリポジトリ側の feat/uiux-audit HEAD（1a038b6、当該タスクの変更を含まない状態）でも同じ手順で同じ箇所が失敗することを確認済みで、特定のタスクの変更に由来するものではない。

テスト順序への依存が疑われる。フル実行では先行するテストが作った状態に依存して通っているだけ、という可能性がある。その場合、テストが検証しているつもりの内容と実際に検証している内容が食い違っている。

TASK-434（metaCasRace が単体実行では失敗し負荷下では通る）と現象の向きが逆だが、いずれも実行文脈に依存して結果が変わる問題なので、原因調査の際は関連を確認すること。
