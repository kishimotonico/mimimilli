## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
ドッグフーディングのフィードバックを受けた没入モード（再生中タブ）の改善。現状、マウス操作でタイトルが暗いスクリム付きでシークバー付近に復帰表示され、カバー主役の画面を邪魔してやかましい。また中央クリックの再生/停止に視覚フィードバックが無く分かりづらい。

確定仕様:
1. タイトル表示の改善（.mle-nowplaying__immersive-title 周辺）
- 暗いスクリム/黒影の背景を廃止し、小さめの文字＋軽いtext-shadowだけの表示にする
- 表示位置を画面左上（右上の切替アイコンと対角）へ移動。シークバー付近には置かない
- 表示タイミング: マウスアクティブで表示・アイドルでフェード（既存タイマー流用）に加え、没入モードへの切替時とトラック切替時にも数秒表示してから自動フェード
2. 再生/停止のバーストフィードバック
- 再生⇄一時停止が切り替わった瞬間、画面中央に⏸/▶アイコンを短時間（0.6〜0.8秒目安）ポップ表示してフェードアウト（YouTube方式）。中央クリック・下記の最小UIボタン・キーボードなど契機を問わず没入モード中は表示
- motion（導入済み）で軽いスケール＋フェードのアニメーション。定常的な状態表示は追加しない
3. マウスアクティブ時の最小コントロール（試験導入。やかましければ後日削除する前提で、疎結合に実装）
- シーク行の直下（通常モードでトランスポート行が占める帯域＝没入では現在空き）に、背景パネルなしのゴーストボタン列を表示: 左寄りに 前トラック・再生/停止・次トラック、右寄りに音量（既存の音量UI部品を流用してよい）
- 白系アイコン＋軽いシャドウで暗いカバー上でも視認可能に。マウスアクティブで表示・アイドルでフェードし、シークバーだけが残る（既存フェード対象に追加）
- ボタン上のクリックはボタン操作、それ以外のカバー領域クリックは従来どおり再生/停止トグル

絶対条件:
- シーク行のDOMノード・寸法・位置は一切変えない（最小UIをシーク行のflex内に入れない。既存のDOMノード同一性・getBoundingClientRect不変テストが通り続けること）
- Esc・切替アイコン・中央クリック・localStorageモード記憶など既存仕様は維持
- 通常モードの見た目・挙動は変更しない

運用: masterからブランチを切り .worktrees/<タスクID> で作業。UIレイアウト変更のため pnpm test:smoke 必須。実機確認スクショを報告に含める
