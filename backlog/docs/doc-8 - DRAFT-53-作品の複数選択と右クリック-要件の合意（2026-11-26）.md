# DRAFT-53 作品の複数選択と右クリック 要件の合意（2026-11-26）

DRAFT-53 はドラフトのため本文を編集できない。要件検討で合意した内容をここに置く。着手はUIプリミティブの土台（Base UI 導入とメニュー等の置き換え）が整ってから。確認に使ったモック: https://claude.ai/artifact/VsoYpwercqVXnZ1YvcsLEV

## 選び方
- クリックは単一選択（現行どおり詳細ペインが開く）
- Ctrl/Cmd+クリックで追加・解除、Shift+クリックとShift+矢印で範囲選択、普通の矢印キーは単一選択で移動
- Ctrl/Cmd+A で表示中の一覧の全件を選ぶ。未読み込みの分も含むため、一覧と同じ条件で作品IDだけを返すAPIを足す。一括操作のAPIはすべて作品IDの一覧を受け取る
- Esc・一覧の背景クリックで解除。フォルダーや絞り込みを切り替えたら解除。複数選択はURLに載せない（単一選択の ?work= は現行どおり）
- チェックボックスは置かない
- gridでも範囲の先端（カーソル作品）が見えるようにする

## 選択中の見せ方
- 2件以上選ぶと詳細ペインは閉じる（ペインは一覧に重なる作りのため、選んだ作品を隠さない）
- チップ帯右端の件数表示を「12 / 248 件を選択」に変え、横に解除の×を置く。複数選択専用の操作パネルや下部バーは作らない（不採用: 詳細ペインに一括操作パネルを出す案、下部に操作バーを出す案。操作の入口が単一選択時と分かれ、ボタンがメニューの写しになるため）

## 操作の入口
- 選択は対象を決めるだけで、操作は単一選択時と同じ入口（右クリック）から呼ぶ
- 作品の右クリックメニュー: 再生（1件時）／お気に入りに追加 または お気に入りから外す（対象がすべてお気に入りなら外す、の1項目）／タグを追加…／編集…（1件時）／区切り／登録解除…（複数時は件数を右端に）。「DLsite情報を更新…」は DRAFT-86 で足す
- 選択中の作品の上で右クリックしたら選択全体が対象、選択外なら1件に選び直してから開く
- 作品一覧の背景の右クリック: すべて選択／表示の切り替え／検索を保存（絞り込み中のみ）
- Deleteキーで登録解除の確認を出す
- タグを追加…は小さなダイアログで、候補の横に「N件に付与済み」を出す。既存の TagCombobox 相当を使う
- 登録解除の確認文: 「12件の作品を登録解除しますか？」「再生履歴・ブックマーク・タグなどのユーザーデータも消えます。ファイルは削除されず、再スキャンすると登録し直せますが、ユーザーデータは戻りません。」
- エラーのスマートフォルダーの「欠損作品をまとめて削除」バナー（TASK-355）は残す（missingだけを対象にする安全策のため）

## 右クリックの全体方針
- アプリ全体でブラウザのコンテキストメニューを止める。例外は入力欄と、選択できるテキストを選択しているときだけ
- メニューを出すのは当面、作品一覧（作品と背景）だけ。ほかの場所（サイドバー行の DRAFT-84 など）は項目が必要になったときに足す
- メニューは PopupMenu の流用ではなく、UIプリミティブの土台（Base UI を推奨で評価中）の ContextMenu で作る。サブメニューに対応できること
- モバイルは対象外（ADR-0006）

## 別扱い
- ドラッグ＆ドロップ（サイドバーの「お気に入り」やタグ1つだけのフォルダーへ落としてタグを付ける）は別のドラフトにする。ドロップの意味は DRAFT-81（プレイリスト）と一緒に決める
- お気に入りをタグの一種にするかは未決
- 一括のDLsite情報の更新は DRAFT-86
