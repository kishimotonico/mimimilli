# ADR-0041: ライブラリを本体にしてサイドバーを1本にし、再生中を重なる層にする

- ステータス: 承認
- 日付: 2026-11-22
- 関連: [ADR-0040](0040-smart-folder-condition-tree.md)（スマートフォルダーのモデルと評価）、[ADR-0031](0031-app-route-navigation.md)（AppRoute と URL 形式を本ADRで改訂）、[ADR-0013](0013-tag-click-replaces-all.md)（タグクリックの行き先・兄弟値ドロップダウンを本ADRで改訂）、[ADR-0012](0012-library-axis-as-value-browse.md)（決定7を本ADRで改訂）、[ADR-0016](0016-view-axis-consolidation.md)（ライブラリ統計の置き場所）、[ADR-0026](0026-value-list-as-global-entry.md)（値一覧の Ctrl+クリックを本ADRで改訂）、[ADR-0006](0006-mobile-ui-strategy.md)（ナビゲーション形態の前提を本ADRで改訂）、[ADR-0042](0042-pragmatic-drag-and-drop.md)（サイドバーの並べ替え）、backlog DRAFT-61

## 文脈

左側のナビゲーションは2段になっている。縦のアイコン列（`client/src/app/ui/LeftNav.tsx`）でファイル・ライブラリ・再生中を切り替え、ライブラリの中ではさらに軸レール（`client/src/features/library/ui/AxisColumn.tsx`）でビュー・分類軸・スマートフォルダーを選ぶ。アイコン列のうち履歴・お気に入り・ピン留めは「近日実装」のまま無効になっている。

ファイル・ライブラリ・再生中は、AppRoute の `mode` として同格に並んでいる（[ADR-0031](0031-app-route-navigation.md)）。再生中を開くと下の画面から離れ、`/now-playing` という別の URL になる。再生バー（bar モード）には再生中画面への直接の入口が無く、ポップアップを開いてから ⤢ を押す2手が要る。

[ADR-0040](0040-smart-folder-condition-tree.md) でライブラリの行がすべてスマートフォルダーになり、軸レールとビューの区別がなくなった。スマートフォルダーの定義はサーバーから来るので、URL だけでは「値一覧か作品一覧か」「`group` の値が何を指すか」が決まらない。今の parse は軸 ID だけから値一覧かどうかを決めている（`client/src/entities/navigation/model/navigationUrl.ts`）。

## 決定

### 全体の構成

ライブラリをアプリの本体にする。ファイルはトップバーの道具、再生中は今の画面に重なる層にする。

| 画面                           | サイドバー                                                       | 再生バー                           | アドレスバー                                                                                             | 戻り方                                                             |
| ------------------------------ | ---------------------------------------------------------------- | ---------------------------------- | -------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| ライブラリ（作品一覧・値一覧） | 出す（隠していれば隠したまま）                                   | 再生中なら出す                     | 左端に開閉ボタン、戻る・進む、パンくず（ライブラリ › スマートフォルダー › 値）、表示形式、並び順メニュー | ブラウザの履歴                                                     |
| 作品詳細                       | 出す。選択中の行は元のスマートフォルダーで、押すと元の一覧へ戻る | 出す                               | 開閉ボタン、戻る・進む、パンくず。表示形式と並び順は出さない                                             | ブラウザの履歴（直前のライブラリ）                                 |
| ファイル                       | 出さない（全幅のカラム表示）                                     | 出す                               | 開閉ボタンは出さない。トップバーのファイルボタンが点灯                                                   | ファイルボタンをもう一度押す、ライブラリへ戻る操作、ブラウザの戻る |
| 再生中の層                     | 層の下に隠れる（状態は変えない）                                 | 出さない（層が自分の操作部を持つ） | 層が覆う。トップバーは残す                                                                               | 閉じるボタン、Esc、ブラウザの戻る                                  |

`LeftNav` と `AxisColumn` はなくし、サイドバー1本にする。ファイルから戻ったときと、作品詳細で選択中の行を押したときは、保持しているライブラリの状態（スマートフォルダー・グループの値・チップ・検索語・今の並び・ランダムの seed）をそのまま使う。

### サイドバー

- 節の見出しは「ライブラリ」1つ。次の段階で「プレイリスト」の節を足すが、今は見出しも出さない
- 画面には「スマートフォルダー」「項目」のような総称を出さず、動詞と行の名前で書く。文書とコードでは「スマートフォルダー」と呼ぶ
- 隠す・出すだけを持つ。アドレスバー左端のボタンと Ctrl+B で切り替え、状態は端末に保存する。画面幅では自動で切り替えない。作品詳細でも同じ状態を使う
- 将来「アイコンだけ＋ホバーで詳細」に広げる余地は残す。Ctrl+B は将来のキーコンフィグで変えられるようにする可能性がある
- 幅の変更は今回は入れない
- 最下部のライブラリ統計（作品数・トラック数・合計時間。[ADR-0016](0016-view-axis-consolidation.md)）は残す
- 件数は、条件が空のスマートフォルダー（すべて・ランダム）とグループ分けを持つものには出さない。「最近再生」には出す
- 0件で隠すスマートフォルダー（既定では「エラー」。隠す条件は [ADR-0040](0040-smart-folder-condition-tree.md)）は、開いている間に0件になっても行と空の一覧を残し、別のスマートフォルダーへ移ったら隠す。件数の取得中・取得失敗は0件として扱わない。編集の状態では0件の行も見せる

見出しの ＋ からは、今の検索の保存（絞り込みが無いときは今のスマートフォルダーの複製）、グループ分けの追加、既定から追加ができる。

見出しの編集の操作で編集の状態に入り、ドラッグで並べ替え（[ADR-0042](0042-pragmatic-drag-and-drop.md)）、名前・グループ分け・既定の並びの変更、削除ができる。編集のダイアログでは、自作のスマートフォルダーの条件をルート直下の子ごとに × で外せる。既定のスマートフォルダーは条件を読み取り専用で見せ、変えられるのは名前・既定の並び・位置と削除だけ。「すべて」は既定の並びと位置だけ（権限の詳細は [ADR-0040](0040-smart-folder-condition-tree.md)）。削除はトーストから取り消せる（サーバーの復元の口で同じ行を戻す）。

グループ分けを持つ行は、今の分類軸と同じくホバーでクイックオーバーレイを出す。値の主クリックはその値の作品一覧（`/library/by-cv?group=値`）へ進み、追加ボタンはチップを足す（行き先は後述）。ドラッグ中はオーバーレイを出さない。

### 並び順メニューと保存の操作

並び順メニューはアドレスバーに置き、今の並びを変える。今の並びが解決後の既定の並び（[ADR-0040](0040-smart-folder-condition-tree.md)）から外れているときだけ、メニューに「この並びを既定にする」を出す。

- 「『すべて』と同じ」のスマートフォルダーで押すと、そのスマートフォルダーだけが自分の並びを持つ。継承に戻すのは編集のダイアログで「『すべて』と同じ」を選ぶ
- 「すべて」で押すと、「『すべて』と同じ」のスマートフォルダー全部の並びも変わる

メニューで変えるたびに保存はしない。保存すると「ランダム」や「最近再生」が性格を失ったまま保存されるからである。

検索の保存の操作は、常設のチップ列の右端に置く。そのために行は増やさない。

| 状態                                                                                                                             | 出す操作           |
| -------------------------------------------------------------------------------------------------------------------------------- | ------------------ |
| 保存先が無い絞り込み（すべて・既定のスマートフォルダー・グループ分けを持つ自作のスマートフォルダーで、値・チップ・検索語がある） | 検索を保存         |
| 自作でグループ分けを持たないスマートフォルダーで、チップを足したか並びを変えた                                                   | 上書き、別名で保存 |
| 自作でグループ分けを持たないスマートフォルダーで、検索語だけを入れた                                                             | 検索を保存         |

- 上書きは、自作でグループ分けを持たないスマートフォルダーにだけ出す。既定のもの（テンプレートの固定 ID を持つもの）には出さない
- 上書きだけは、成功のトーストの「元に戻す」で上書き前の定義へ戻せる。新しく保存したものは削除（これもトーストから元に戻せる）で戻す
- 保存の中身は [ADR-0040](0040-smart-folder-condition-tree.md) の「条件の編集」に従う

保存・上書き・削除のあとの行き先は次のとおりにする。新規保存（検索を保存・別名で保存・＋から作る）は、作ったスマートフォルダーをサイドバーから入るときと同じく絞り込みなしで開く（履歴を積む）。上書きも同じ形で同じスマートフォルダーを絞り込みなしで開き直し（履歴を積む）、保存した絞り込みが条件に入ったので、チップと検索語は消える。削除は、開いているスマートフォルダーなら履歴を積まず置き換えで「すべて」へ移る。作品詳細などライブラリの外の画面にいるときは画面をそのままにして、保持しているライブラリを「すべて」に置き換える。

### スマートフォルダーの切り替えと検索の行き先

スマートフォルダーを切り替えると、チップと検索語は消える。スマートフォルダーは条件の束なので持ち越さない。0件になったときは「すべて」で探す操作を出し、同じチップと検索語のまま「すべて」へ移れるようにする。

タグやチップの行き先は、保持しているライブラリが値一覧か作品一覧かで決める。値一覧はチップと検索語を効かせないので（[ADR-0026](0026-value-list-as-global-entry.md)）、値一覧から足すものは「すべて」へ持っていく。作品詳細や、下がファイルの層から操作したときは、`mode` を `library` にして保持しているライブラリに適用する。

| 操作                                             | 保持しているライブラリが作品一覧のとき | 値一覧のとき           |
| ------------------------------------------------ | -------------------------------------- | ---------------------- |
| プレビュー・作品詳細・再生中の層でタグをクリック | 「すべて」＋そのタグ                   | 「すべて」＋そのタグ   |
| 同じ場所で Ctrl+クリック                         | その一覧にチップを足す                 | 「すべて」＋そのチップ |
| クイックオーバーレイの追加ボタン                 | その一覧にチップを足す                 | 「すべて」＋そのチップ |
| 検索欄に入力                                     | その一覧で検索                         | 「すべて」の検索結果   |

検索欄の入力は、ライブラリの画面の中では履歴を置き換える（1文字ごとに積まない）。作品詳細・ファイルから入力したときは、最初の入力が画面を変える遷移なので履歴を積み、戻るで元の画面へ戻れる。以降はライブラリの中の入力として置き換える。層が開いているときは、遷移の規則どおり層のエントリーを置き換える。

Ctrl+クリックで既定の動作を反転するのは、プレビュー・作品詳細・再生中の層のタグだけに残す。値一覧の値（タイル・行）とクイックオーバーレイの値は、Ctrl+クリックでも主クリックと同じくその値の作品一覧へ進む。

値を選んだあとに隣の値へ移るのは、パンくずの値から兄弟の値を選ぶ形にする。グループの値はチップではなくなったので、チップの兄弟値ドロップダウン（[ADR-0013](0013-tag-click-replaces-all.md)）はこれに置き換わる。

「＋絞り込み」の候補は、定義済みの prefix 全部・タグ・追加年にする。サイドバーのグループ分けとは連動させない。

### 再生中の層

- 入口は再生バーとポップアップの ⤢、作品詳細の「再生画面へ」。再生バーに ⤢ を新しく足す。何も再生していないときは開けない。再生バーは再生中だけ出す
- 層は下の画面の URL に `np=1` を足して表す（例: `/library/fav?np=1`）。`/now-playing` はなくなる
- 層の開き方（アプリの中で開いたか、`np=1` の URL を直接開いたか）を履歴エントリーに持つ。アプリの中で開いたときは、閉じると履歴を1件戻る。直接開いたときは、閉じるときに `np` だけを外す（置き換え）
- 閉じるボタン・Esc・ブラウザの戻るで閉じる。Esc は通常・没入のどちらでも層を閉じる。没入の切り替えはボタンだけ
- 再生していないのに `np=1` のエントリーに着いたとき（再読み込みや「進む」を含む）も、閉じるときと同じ規則にする。アプリの中で積んだエントリーなら1件戻り、それ以外は置き換えで `np` を外す
- 層から別の画面へ進むときは、層の履歴エントリーを置き換える。下の画面がファイルでも同じ規則にする
  - 作品名 → 作品詳細（`mode: "workDetail"`）。ファイルから来ていてもファイルを抜ける。作品詳細で戻ると、層を開く前の画面（ファイルならそのファイルの位置）に着く
  - タグ → 前節の行き先の表に従う（`mode: "library"`）。選択済みのタグでも層は落として一覧へ移る
- route を書く口は「遷移」と「補正」の2つに分ける。遷移（画面へ進む操作）は必ず層を落とす。補正（選択解除・消えたスマートフォルダーからの退避・グループ分けを変えたあとの入り直し・既定の並びの保存後に今の並びを外す・存在しないスマートフォルダーと、グループ分けの無いスマートフォルダーに残った `group` の書き戻し。`normalizeLibraryFolder`）は await のあとにも走るので、library だけを差し替え、画面と層は変えず、履歴は常に置き換える。await を挟む保存・追加のあとは、始めたときと同じ画面（層なし・同じ場所）なら遷移、そうでなければ補正で入り直す

### AppRoute と URL

AppRoute の `mode: "nowPlaying"` をなくし、下の画面とは独立した `layer` を持たせる。今の並びとランダムの seed は `library` に持つ。

```ts
type LibraryRoute = {
  folderId: string; // スマートフォルダーの ID
  group: string | null; // グループ分けで選んだ値。null なら値一覧
  selectedTags: NormalizedTag[]; // チップ
  selectedWorkId: string | null;
  q: string;
  sort: SortId | null; // 今の並び。null なら既定の並び
  seed: number; // ランダムの seed
};

type AppRoute = {
  library: LibraryRoute;
  files: FilesUrlState;
  layer: { kind: "nowPlaying"; openedBy: "app" | "url" } | null;
} & ({ mode: "library" } | { mode: "files" } | { mode: "workDetail"; workId: string });
```

| 画面                 | URL                                      |
| -------------------- | ---------------------------------------- |
| 作品一覧             | `/library/<id>?tags=…&q=…&work=…`        |
| グループ分けの値一覧 | `/library/by-cv`（q・tags は効かせない） |
| 値を選んだ一覧       | `/library/by-cv?group=<値>&tags=…`       |
| 作品詳細             | `/work/<id>`（変更なし）                 |
| ファイル             | `/files/<relPath>?sel=…`（変更なし）     |
| 再生中の層           | 下の画面の URL に `np=1` を足す          |

- グループの値はパスではなくクエリに置く。タグ別の値は `cv/〇〇` のようにスラッシュを含み、パスのセグメントでは扱えない
- `sort` と `seed` は URL に載せない。履歴エントリーの状態に書く

URL とスマートフォルダーの定義の突き合わせは、純粋関数 `resolveLibraryView(route.library, folders)` 1つで行う。

- 存在しないスマートフォルダーなら `all` へ。グループ分けを持たないのに `group` があれば無視する。route 側も補正で書き戻し、URL からも外す
- 条件が読めないスマートフォルダー（[ADR-0040](0040-smart-folder-condition-tree.md)）は開けない状態として返す。画面は削除だけを出す（「すべて」は削除を出さない）
- 並びは選んだ行に要るときだけ解決する（今の並び → 行の既定 → 「すべて」の既定）。「すべて」の行が読めなくても、固有の並びを持つ行は開ける。並びを継承する作品一覧で「すべて」の並びが読めないときは、理由を出して開かない。値一覧は並びを要さない
- 値一覧なら q・tags を効かせない。parse では落とさず、ここで無視する
- 値一覧か作品一覧か、パンくず、API に渡す条件の材料と解決済みの並びを返す

画面・クエリ・パンくず・遷移関数はこの結果だけを読む。スマートフォルダーの一覧はすべての前提になるので、起動時に先読みする。

### 履歴エントリーごとの状態

今の並び・ランダムの seed・層の開き方は AppRoute に持つ。sort・seed を履歴エントリーに書くのはライブラリ画面のときだけで、ほかの画面のエントリーには層の開き方だけを書く。codec が「URL に出す部分」と「履歴エントリーの状態に書く部分」に分ける。同期は popstate と初回ロードで履歴エントリーの状態も読み戻す。同期は今までどおり項目名を参照しない汎用の仕組みにし、どれを URL に出しどれを履歴エントリーに書くかは codec が決める。

- 今の並びは、戻る・進む・作品詳細からの戻り・ファイルからの戻りでは保たれる。端末にも DB にも URL にも書かない
- ランダムの seed は、開いている間（ページ送り、詳細から戻る、お気に入り後の再取得）は変わらない。今はアプリ全体に1つの `randomSeedAtom` を、`library.seed` に移す
- サイドバーから入り直すと、遷移の純粋関数が `sort: null` と新しい seed を入れる。「並べ直す」も新しい seed を入れる
- seed はクライアントだけが発行する（[ADR-0040](0040-smart-folder-condition-tree.md)）。URL を直接開いて履歴エントリーの状態が無いときは、クライアントが seed を作り、置き換えで履歴エントリーに書く

## 帰結

- 縦のアイコン列と軸レールの2段がなくなり、ナビゲーションはサイドバー1本とトップバーの道具になる。履歴・お気に入り・ピン留めの無効なアイコンも消える
- 再生中を開いても下の画面が残り、閉じれば元の場所から探索を続けられる。再生バーからも1手で開ける
- [ADR-0031](0031-app-route-navigation.md) の「URL 形式は変えない」は成り立たなくなる。`/now-playing` が消え、`/library/<軸>` は `/library/<スマートフォルダー ID>` に、`sort=` は URL から消える。古い URL の読み替えは用意しない。nowPlaying 系の smoke は書き換える
- ADR-0031 の AppRoute から `mode: "nowPlaying"` が抜け、`layer`・`group`・`seed` が入る。`library.sort` は AppRoute に残るが URL からは抜ける。同期は URL に加えて履歴エントリーの状態も読み書きするようになる。ADR-0031 が URL と無関係な状態とした `randomSeedAtom` は、`library.seed` として route に入る
- 今の並びを開き直しで保てなくなる。サイドバーから入り直すと既定に戻るので、よく使う並びは「この並びを既定にする」で保存する必要がある
- [ADR-0013](0013-tag-click-replaces-all.md) の作品詳細のタグクリックは「今の軸で完全置換（値一覧なら『すべて』へ）」から「常に『すべて』＋そのタグ」に変わる。ADR-0013 の「Ctrl+クリックの反転は全入口で維持」は、プレビュー・作品詳細・再生中の層のタグだけに狭まる。クイックオーバーレイと値一覧の値は、タグの置換ではなくグループの値の選択になり、Ctrl+クリックでも反転しない。チップの兄弟値ドロップダウンは、パンくずの値から兄弟の値へ移る形に置き換わる
- [ADR-0012](0012-library-axis-as-value-browse.md) 決定7 の軸レールのホバーとクリックは、グループ分けを持つ行のクイックオーバーレイとして残る。ドラッグ中は止まる。決定7 の「どの入口でも `Ctrl`+クリックで既定動作を反転する」は、上と同じくタグの入口だけに狭まる
- [ADR-0026](0026-value-list-as-global-entry.md) の「値一覧の Ctrl+クリックはタグの反転」はなくなる
- 作品詳細でもサイドバーが出るので、詳細を見ながら別のスマートフォルダーへ移れる
- サイドバーはデスクトップ専用である。[ADR-0006](0006-mobile-ui-strategy.md) の LeftNav・AddressBar を前提にした記述と、ボトムタブ「ライブラリ / スマートフォルダー / お気に入り」は、すべてがスマートフォルダーになったので、モバイルに着手するときに考え直す
- 幅の変更、アイコンだけの表示、⌘K の移動パレットは次の段階に回す
