# ADR-0016: ホーム軸と未再生ビューを廃止し、欠損ビューを包括エラービューへ統合する

- ステータス: 承認
- 日付: 2026-08-11
- 関連: [ADR-0012](0012-library-axis-as-value-browse.md)（本ADRで決定4を廃止）

## 文脈

ADR-0012 決定4 は発見ダッシュボード（DiscoveryDashboard）を独立したホームビューとして残すと定めた。しかしドッグフーディング（2026-08-11）の結果、ホームは実質使われていなかった。最近追加・最近再生は同名のビュー軸で足り、ランダムピックはソートのランダム（シード付きで実装済み）と重複する。ホーム軸だけが専用の描画パス（`PreviewPane` の home モード、`LibraryView` の分岐）を持ち、レイアウト一本化の妨げにもなっていた。

同時に、未再生（unplayed）ビューも使われておらず、ファイル欠損（missing）ビューは作品ステータスに `error`（メタ不整合等）があるのに欠損しか表示しない中途半端な範囲だった。

## 決定

1. ホーム軸を削除する。全軸を同一レイアウト（軸レール＋結果面、作品選択時のみ右ペイン）に一本化する。`/library/home` は無効なURLとしてデフォルト軸（all）へフォールバックする
2. ホームにあったライブラリ統計（作品数・トラック数・合計時間）は軸レール最下部の常時表示へ移設する。ランダムピックの代替として、ソートがランダムのときだけ再シャッフルボタンを表示する（クライアントがシードを発行し直す）
3. 未再生（unplayed）ビューを削除する。予約語からも外す
4. ファイル欠損（missing）ビューは、`status !== "ok"`（missing と error の両方）を対象とする「エラー」ビュー（ID: `error`）へ改名・拡張する。該当0件のときは軸レールに表示せず、1件以上で件数バッジ付きで表示する

ビュー軸は `all / recent / added / fav / error` の5つになる。

## ADR-0012 からの改訂点

決定4（発見ダッシュボードの独立ホームビュー化）を廃止する。値ブラウズ・ファセット軸に関する他の決定は変更しない。

## 帰結

- `DiscoveryDashboard` / `WorkCard` とホーム専用スタイル・分岐は削除された。復活が必要になれば Git 履歴から取り出す
- エラービューの件数は専用APIを設けず、既存 `GET /works?view=error&limit=1` の `total` を流用する
- ライブラリ統計のデータ源（`libraryStatsQuery`）はスキャンモーダルの件数表示と共用のため維持する
- 実装は TASK-302〜305（統合ブランチ `feat/axis-rework`）
